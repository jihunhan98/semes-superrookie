## 이 프로젝트의 스택

- **Spring Boot 3.3.4** (`backend/pom.xml`)
- **Java 21**
- **Spring Web MVC** (`spring-boot-starter-web`) — REST API
- **Spring Data JPA** (`spring-boot-starter-data-jpa`) — Hibernate 기반 ORM
- **Bean Validation** (`spring-boot-starter-validation`) — `@Valid`, `@NotBlank` 등
- **Lombok** — `@RequiredArgsConstructor`로 생성자 보일러플레이트 제거
- **Oracle** (`ojdbc11`) — 운영 DB

세션·JWT·Spring Security는 의도적으로 **안 씀** (`기능명세서.md` 참고 — 학습/과제 목적상 단순화). 그래서 "로그인 상태 유지"는 프론트 `sessionStorage`가 담당하고, 백엔드 API는 매 요청마다 `userId`를 파라미터로 직접 받는다. 이 부분은 실무 표준과 다르다는 걸 인지하고 보는 게 좋다 — 표준이라면 `Authorization` 헤더 + 토큰 검증 필터가 그 자리를 대신한다.

        ├── entity/{Project,Membership,ProjectToken,Role}.java
