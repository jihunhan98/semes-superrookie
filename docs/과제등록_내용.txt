주제
고객 요구사항 검토 및 개발 산출물 자동 생성 도구

내용
삼성전자에서 받는 VCS 요구사항 명세서를 검토하고, 개발에 필요한 산출물을 만드는 작업을 자동화한다.

요구사항 중에서 해석이 애매하거나 서로 충돌하는 부분을 먼저 찾아 확정하고, 확정된 요구사항을 기준으로 개발 이슈와 SWVOC, 기능·비기능 요구사항, 상세 설계 초안을 생성한다. 요구사항과 산출물을 서로 연결해 두어, 나중에 요구사항이 바뀌면 어떤 산출물이 영향을 받는지 바로 확인할 수 있다.

사내 폐쇄망 환경을 고려해 외부 API 없이 사내 LLM과 로컬 모델로 동작하도록 구성한다.
