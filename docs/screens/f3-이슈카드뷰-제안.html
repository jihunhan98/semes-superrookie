After제안 — 이슈 카드 + 산출물 4종 pill

이슈 하나 = 카드 하나. 왼쪽 색상바는 "이슈 나누기" 화면에서 이 이슈를 표시했던 색을 그대로 이어받습니다 — 어느 문장에서 나온 이슈인지 색으로 계속 따라갈 수 있게. 산출물 4종은 세로 4줄 대신 가로 pill 4개로 압축됩니다.

색이 이슈 나누기 화면과 이어짐

split 화면에서 이 이슈 경계를 표시했던 색(빨강·주황·보라 …)을 카드 왼쪽 바에 그대로 씀 — 같은 이슈라는 걸 색으로 계속 알아볼 수 있음.

📐
산출물 4종 = 세로 4줄 → 가로 4개 pill

이슈가 늘어도 카드 높이가 거의 안 늘어나서, 그리드로 여러 개를 한 화면에 스캔하기 쉬움. pill 하나 클릭하면 그 산출물 상세로 바로 이동(지금과 동일).

💬
구절 미리보기 2줄

제목만으론 "이게 뭘 다루는 이슈였지?"가 안 보일 때, 이슈 나누기에서 사람이 확정한 quote를 그대로 보여줘서 바로 기억나게 함.

진행 상태 배지는 일부러 안 넣었습니다. "검토중/완료" 같은 상태를 지금 실제로 추적하는 데이터가 없어서(산출물 자체가 아직 UI 목업), 있지도 않은 상태를 표시하면 거짓 정보가 됩니다 — 실제 상태 추적이 붙으면(기능 3 산출물 관리) 그때 pill 옆에 작은 점이나 테두리 색으로 추가하는 걸 권합니다.
