요구사항 엔지니어링 — 기능 1 (로그인 · 프로젝트 관리)

서비스에 처음 들어오는 관문. 로그인/회원가입 후 프로젝트를 나열하고, New Project로 새로 만들거나 프로젝트 카드를 클릭해 이미 속한 프로젝트를 열거나, Open Project로 토큰을 넣어 아직 안 속한 프로젝트에 참여한다. 헤더 왼쪽 로고를 누르면 홈(로그인 상태면 프로젝트 목록, 아니면 로그인 화면)으로 돌아가고, 우측 로그아웃 버튼으로 세션을 정리한다. 프로젝트를 열면 프로젝트 홈(조회 전용, 사이드바+헤더)으로 들어가고, 설정은 사이드바에서 별도로 들어가는 구분된 화면이다. 여기서 관리되는 값은 DB에 저장되어 팀 전체가 공유한다. 이 화면들을 지나면 기능 2(요구사항)로 들어간다.

기능 1 화면 흐름

1로그인 · 회원가입

사번+비밀번호. 계정이 확정·수정 이력의 작성자가 된다.

2프로젝트 목록

내가 속한 프로젝트 카드 나열 + New Project / Open Project. 카드 클릭이 곧 열기.

3새 참여 = 토큰

아직 안 속한 프로젝트는 Open Project에서 접근 토큰으로 참여.

4홈 vs 설정

프로젝트를 열면 항상 홈(조회)으로 가고, 편집은 사이드바의 설정에서 따로 한다.
