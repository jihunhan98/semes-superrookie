요구사항 엔지니어링 — 기능 2 (요구사항 검토)

프로젝트 홈(기능 1, /projects/{id})에서 사이드바 "요구사항"을 누르면 목록이 바로 뜬다(기본 진입 화면). "＋ 새 요구사항"은 별도 페이지로 이동한다 — 다이얼로그도, 문서 업로드도 없음. 등록 페이지는 왼쪽 입력·오른쪽 AI 검출 결과 구성이며, 검출 항목마다 수용/패스를 고를 수 있고 이 요구사항을 AI 검토 대상에 포함할지도 선택한다. 등록 후에는 상세 화면에서 AI로 불명확·상충을 검토해 확정하며, 확정·수정마다 버전이 커밋처럼 쌓인다. 로그인·프로젝트 선택·홈 대시보드는 기능 1에서 이미 구현되어 있어 이 문서에서는 다루지 않는다.
