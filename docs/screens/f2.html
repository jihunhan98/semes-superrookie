요구사항 엔지니어링 — 기능 2 (요구사항 검토)

프로젝트 홈(기능 1, /projects/{id})에서 사이드바 "요구사항"을 누르면 목록이 바로 뜬다(기본 진입 화면). "＋ 새 요구사항"은 별도 페이지로 이동한다 — 다이얼로그도, 문서 업로드도 없음. 등록 시 AI 검토를 받거나 패스할 수 있고, 등록 후에는 상세 화면에서 AI로 불명확·상충을 검토해 확정하며, 확정·수정마다 버전이 커밋처럼 쌓인다. 화면 UI보다 먼저 아래 프로세스 흐름을 보면 전체 그림이 잡힌다. 로그인·프로젝트 선택·홈 대시보드는 기능 1에서 이미 구현되어 있어 이 문서에서는 다루지 않는다.

🔀 AI 검토가 일어나는 두 가지 경우 — 성격이 다르므로 화면도 분리한다

같은 "AI 검토"라도 왜 검토하는지가 다르다. 최초 확정은 처음 쓴 문장이 명확한지를 보는 것이고, 수정은 이미 합의된 문장을 왜·어떻게 바꾸는지를 보는 것이다. 그래서 최초 확정에는 수정 사유가 없고, AI가 보는 범위도 다르다.
