내용은 작성 안내이며 실제 고객 데이터가 아닙니다. 현재 고정 스키마의 필드를 보여주며, 모든 항목을 필수 입력으로 새로 강제하는 문서는 아닙니다.

현상현재 문제 또는 변경 배경을 작성합니다. 제공되지 않은 기존 동작은 추측하지 않습니다.
개선 요구구현할 동작과 완료 여부를 판단할 수 있는 조건을 작성합니다.

제약 조건기술적·업무적 제약과 추가 확인 사항을 작성합니다.
변경 전현재 동작을 작성합니다. 기존 요청대로 작성 내용이 없으면 화면에는 “없음”을 표시합니다.
