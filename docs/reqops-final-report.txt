슈퍼루키 최종보고 | ReqOps 주요 개발 내역

고객 요구사항 등록부터 AI 검토, 담당자 확정, 개발 산출물 생성, 변경 영향 확인까지 이어지는 요구사항 관리 도구를 개발함.

1. 고객 요구사항 등록 및 AI 기반 검토 기능 개발
   - 요구사항 원문 등록과 동시에 AI 검토를 시작하도록 구현.
   - 동작 조건·수치·판단 기준의 모호함, 수행 주체·중요 예외의 누락, 기존 요구사항과의 충돌을 검토하고 해당 원문 구절과 수정 이유, 수정안을 표시.

2. AI 수정안 검토·반영 및 고객 합의·버전 관리 기능 개발
   - 담당자가 원문과 AI 수정안을 비교하고, 항목별로 적용·직접 수정·제외를 선택한 뒤 최종 본문을 확정하도록 구현.
   - 본문 변경 시 고객 합의 내용과 변경 요약을 기록하고 확정 버전별로 이력을 관리. 본문이 동일한 경우 별도 합의 입력 없이 확정 가능.

3. 프로젝트 용어사전 자동 추출 및 관리 기능 개발
   - 요구사항에서 AMR·SOC 등 프로젝트 핵심 용어와 사용 구절을 추출하고, 담당자가 정의를 수정·확정할 수 있도록 구현.
   - 프로젝트 용어사전을 후속 AI 검토에 반영.

4. AI 기반 개발 이슈 분할·도출 기능 개발
   - 확정된 요구사항을 구현 단위의 개발 이슈로 나누고 각 이슈를 요구사항 원문 근거와 연결.
   - 담당자가 이슈의 내용과 변경 범위를 검토·수정하고 확정할 수 있도록 구현.

5. AI 기반 개발 산출물 4종 자동 생성 및 검토·확정 기능 개발
   - 개발 이슈별로 SWVOC, 기능 요구사항, 비기능 요구사항, 상세 설계 초안을 정해진 양식에 맞춰 생성.
   - 기능·비기능의 동작 시나리오는 표로, 상세 설계의 클래스·시퀀스는 다이어그램으로 표시하고 이슈와 산출물을 검토·확정하는 화면을 구현.

6. 요구사항 변경 영향 모니터링 및 알림 기능 개발
   - 새로 등록하거나 변경한 요구사항을 기존 요구사항과 비교해 충돌하거나 함께 확인할 항목을 찾아 담당자에게 알림.
   - 비교 화면에서 양쪽 원문과 영향 이유를 확인하고, 알림을 사용자별로 읽음 처리할 수 있도록 구현.

7. 요구사항·개발 이슈·산출물 통합 조회 화면 개발
   - 요구사항에서 개발 이슈와 산출물로 이어지는 관계를 트리로 표시하고, 종류·상태 필터와 검색을 구현.
   - 산출물 생성 및 확정 상태를 목록과 상세에 일관되게 표시하고, 확정 완료 건은 해당 산출물로 바로 이동하도록 개선.

8. Jira 프로젝트 설정 및 개발 이슈 연동 기능 개발
   - ReqOps 프로젝트에 여러 Jira 프로젝트를 연결할 수 있도록 설정 화면과 저장 기능을 구현.
   - 개발 이슈와 산출물 내용을 Jira 이슈 생성 요청에 담고 생성된 이슈를 열 수 있도록 연동 경로를 구현.

9. 사내 폐쇄망 실행 환경 구성
   - Spring Boot·Oracle 백엔드, Next.js 화면, FastAPI AI 서버와 사내 LLM을 연결하는 구조를 구성.
   - 폐쇄망에서 npm 설치 없이 실행할 수 있도록 프런트엔드 배포본과 실행 스크립트를 구성.
