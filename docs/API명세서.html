API 명세서

요구사항 엔지니어링 — API

Base /api · application/json · 세션/토큰 없음(로그인은 일치 확인만, 이후 요청에 userId 동봉).

표에서 간략히 보고, 행을 클릭하면 요청·응답 상세가 펼쳐집니다.   표기: * 필수 · 타입 str/num/arr.
