가용 AMR 매칭

개요 🤖 AI 도출
역할Host의 태스크 할당 요청에 대해 조건을 만족하는 가용 AMR을 선별·매칭한다.
목적할당 지연·오배정을 방지하고 우선순위에 따라 최적의 AMR을 배정한다.
동작 정의 🤖 AI 도출 · 동작 유형 3그룹 × (선행·후행·시나리오)
동작 유형선행 조건후행 조건시나리오
기본정상 흐름 가용 AMR ≥ 1대, 요청 유효1대 매칭·상태 BUSY 전환요청 수신 → 가용 필터 → 우선순위 정렬 → 최상위 매칭 → 회신
동일 우선순위 다수 존재대기시간 최장 AMR 선택정렬 → 동점 시 FIFO 규칙 적용 → 매칭
요청에 목적지 좌표 포함경로 산출 가능 AMR 매칭가용 필터 후 pathsearch로 도달성 확인 → 매칭
변형조건 분기 특정 Probe Card 전용 AMR 지정지정 유형 AMR만 매칭카드 타입 파싱 → 호환 AMR 하위집합 필터 → 매칭
긴급(HIGH) 플래그 요청정렬보다 우선 즉시 배정큐 선점 → 가용 중 최근접 AMR 즉시 매칭
배터리 임계 근접 AMR 포함임계 이상만 후보 유지가용 필터 시 배터리 ≥ 30% 조건 추가 → 매칭
예외오류·실패 가용 AMR 0대PENDING 반환·재시도 예약필터 결과 공집합 → 대기 등록 → 가용 변화 이벤트 구독
매칭 직후 대상 AMR 알람매칭 취소·재할당 트리거알람 수신 → 매칭 롤백 → AMVCS30-78 재할당 호출
요청 필수 필드 누락400 거절·오류 코드 회신스키마 검증 실패 → 매칭 미수행 → 오류 반환
제약 사항 🤖 AI 도출
매칭 응답 200ms 이내 · 동시 요청 시 우선순위 큐 순서 보장 · 상태 전환은 원자적(atomic) 처리로 이중 배정 방지.
