AI 협업 기반 요구사항 엔지니어링

삼성전자가 보낸 요구사항을 AI로 검토한다. 불명확·상충을 찾아 확정하고, 산출물을 도출하며, 요구사항↔산출물 연결을 추적한다. 세 기능 중 요구사항 검토가 먼저 구현되어 있다.

구현됨
핵심 기능 1
요구사항 검토
불명확·상충되는 요구를 검출·제안하고, 고객과 협의해 확정·관리한다.
열기 →
미구현
핵심 기능 2
산출물 도출
확정 요구사항에서 산출물 5종(티켓·명세·설계 등) 초안을 자동 도출한다.
자세히 →
미구현
핵심 기능 3
산출물 관리 (추적성)
요구사항↔산출물 연결을 조회하고, 변경 영향을 추적한다.
자세히 →

아키텍처: React(Next.js) → Spring Boot → FastAPI(AI) · 로컬 Qwen3-8B / 사내 GPT-OSS · 반출 차단 환경

req-tf-01태스크 전개⚠ 모호 · 2건
비고동일 자재 ID에 대한 복수의 태스크 생성 허용 여부 등 상세 제약을 정의한다.
‘허용 여부’ = 동일 자재 ID에 대해 최대 1건만 허용, 초과 요청은 거절한다.
확정
req-tf-03맵🔒 확정
해결 전 (원본)
입출고지 값에 와일드카드 사용을 허용한다.
해결 후 (확정 해석)
입출고지 값에 ‘*’(0자 이상)·‘?’(1자) 허용, 대소문자 무시 매칭을 적용한다.

해결 입력

  • [해결하기] → 확정 해석 입력창 인라인 오픈
  • 텍스트영역 + [확정](emerald)
  • 빈 값이면 확정 불가(경고)

확정 카드(전후)

  • 테두리 emerald, 🔒 확정
  • 해결 전/후 2열 비교
  • 전=취소선 / 후=indigo 강조

인터랙션

  • 확정 시 카드가 amber→emerald로 전환
  • KPI 해결/미해결 수 즉시 갱신
  • 확정본은 기능 2로 전달 가능

연동 API

  • POST /requirements/{id}/confirm
  • 이력: GET /{id}/history
  • 본문: before, after, 확정자, 일시
