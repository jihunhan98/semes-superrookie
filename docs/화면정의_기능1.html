GitHub(Primer) 디자인 언어로 다시 잡았습니다. 왼쪽은 앱 섹션 네비게이션(요구사항 리스트 중복 제거), 메인은 대시보드, 로그인으로 작성자 이력을 남기고, 확정·수정마다 버전이 커밋처럼 쌓입니다.

v2 → v3 변경점

1좌측 = 섹션 네비

요구사항 리스트 중복 제거. 좌측은 대시보드·요구사항·산출물·추적성·활동·설정. 리스트는 ‘요구사항’ 안으로.

2메인 = 대시보드

통계 + 활동 피드(누가 뭘 확정) + 내 작업 + 최근 버전. 실제 서비스 홈처럼.

3로그인 + 작성자

사번/SSO 로그인. 모든 확정·수정에 작성자·시각 기록.

4버전 = 커밋

확정 시 버전 생성, 수정 시 새 버전. Git 커밋 이력처럼 쌓고 diff.
