요구사항 엔지니어링 — 기능 1 UI 설계

정보구조를 요구사항 중심으로 다시 잡았습니다. 왼쪽엔 “3대 기능”이 아니라 프로젝트의 요구사항 목록이 놓이고, 검토·도출·추적은 선택한 요구사항의 탭이 됩니다. 확정하면 시맨틱 버전이 매겨지고 버전별로 비교할 수 있습니다.

데스크톱 1920 × 1080 요구사항 중심 IA 버전 관리 · 1.0.0 → 1.0.1

무엇이 바뀌었나

1좌측 = 요구사항 목록

3대 기능 나열을 없앴다. 왼쪽은 이 프로젝트의 모든 요구사항 — 상태·버전과 함께 한눈에.

2기능은 “탭”으로

검토 · 산출물 도출 · 추적성은 선택한 요구사항의 탭. 요구사항을 중심에 두고 작업이 딸려온다.

3확정 = 버전 부여

해석을 확정할 때마다 1.0.0 → 1.0.1 버전이 찍히고, 버전 이력 탭에서 diff로 비교.
