# 기능명세서 — 기능 1 (로그인 · 프로젝트 관리)

> 표기: `FR-1-nn` (Functional Requirement). 우선순위 **P0**(필수) / **P1**(중요) / **P2**(선택).
> 범위: **인증 + 프로젝트(기반 계층)**. 요구사항 검토·산출물 도출·추적성은 기능 2~3에서 다룬다.
> 화면 참조: `docs/화면정의_기능1.html` (화면 1~5).

---

## 1. 개요

- **목적**: 서비스 진입 관문. 계정으로 로그인한 뒤, VS Code처럼 **프로젝트를 만들거나 토큰으로 열고**, 프로젝트 정보를 관리한다. 이후 모든 기능(요구사항·산출물)은 **열린 프로젝트 안에서** 동작한다.
- **역할(Role)**: `OWNER`(프로젝트 소유자) / `MEMBER`(참여자).
- **핵심 원칙**: 프로젝트·멤버·토큰·설정은 전부 **DB에 저장**되어 팀 전체가 공유한다.
- **화면 흐름**: 로그인 → (회원가입) → 프로젝트 목록 → New Project / Open Project(토큰) → 프로젝트 설정.
- **스택**: Next.js(프론트) → Spring Boot(Java 21, API) → Oracle(DB). *AI 엔진은 기능 1에서 사용하지 않는다.*

## 7. 권한 규칙

| 동작 | OWNER | MEMBER |
|---|---|---|
| 프로젝트 열람 · 요구사항 작업 | ✓ | ✓ |
| 기본 정보 수정 | ✓ | ✕ |
| 토큰 발급·재발급 / 멤버 초대·역할 변경 | ✓ | ✕ |

## 8. 데이터 모델 (엔티티)

| 엔티티 | 주요 속성 | 비고 |
|---|---|---|
| **User** | id, 사번(unique), 이름, 부서, password_hash, created_at | 로그인·작성자 |
| **Project** | id, 이름, 고객사, 설명, created_by(User), created_at | |
| **Membership** | id, user_id, project_id, role(`OWNER`/`MEMBER`), joined_at | (user, project) unique |
| **ProjectToken** | id, project_id, token(unique), issued_by, issued_at, revoked(bool) | Open Project·초대에 사용 |
| **ProjectModule** | id, project_id, module_name | 프로젝트별 대상 모듈 |

관계: `User 1—N Membership N—1 Project` · `Project 1—N ProjectToken` · `Project 1—N ProjectModule`.

## 9. API (초안)

| 메서드 · 경로 | 설명 |
|---|---|
| `POST /api/auth/signup` | 회원가입 |
| `POST /api/auth/login` | 로그인(세션/JWT 발급) |
| `POST /api/auth/logout` | 로그아웃 |
| `GET /api/me` | 내 계정 정보 |
| `GET /api/projects` | 내가 참여한 프로젝트 목록 |
| `POST /api/projects` | 프로젝트 생성(생성자=OWNER, 토큰 자동 발급) |
| `POST /api/projects/join` | `{token}`으로 참여 |
| `GET /api/projects/{id}` | 프로젝트 상세 |
| `PATCH /api/projects/{id}/settings` | 기본 정보·대상 모듈 수정 |
| `GET /api/projects/{id}/members` | 멤버 목록 |
| `POST /api/projects/{id}/tokens` | 토큰 발급·재발급(이전 폐기) |
