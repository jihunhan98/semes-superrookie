# 기능명세서 — 기능 1 (로그인 · 프로젝트 관리)

범위: 아이디(사번)·비밀번호 인증 + 프로젝트 생성/참여/설정. 세션·JWT·AI 미사용. 스택: Next.js → Spring Boot → Oracle.

## 기능 요구사항

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| FR-1-01 | 회원가입 | 이름·사번·부서·비밀번호로 계정 생성. 사번 중복 불가 | P0 |
| FR-1-02 | 로그인 | 사번·비밀번호 일치 확인만 (세션/토큰 없음) | P0 |
| FR-1-10 | 프로젝트 목록 | 내가 참여한 프로젝트 목록 | P0 |
| FR-1-11 | 프로젝트 생성 | 이름·고객사·설명·대상 모듈로 생성. 생성자=Owner, 접근 토큰 발급 | P0 |
| FR-1-12 | 프로젝트 참여 | 접근 토큰으로 Member 합류 | P0 |
| FR-1-13 | 프로젝트 열기 | 프로젝트 진입(이후 기능 2로) | P0 |
| FR-1-20 | 기본 정보 수정 | 이름·고객사·설명·대상 모듈 수정 (Owner) | P0 |
| FR-1-21 | 토큰 재발급 | 접근 토큰 재발급, 이전 토큰 폐기 (Owner) | P1 |
| FR-1-22 | 멤버 관리 | 멤버·역할 조회, 초대(토큰 공유) (Owner) | P1 |

## 데이터

- **User**: 사번(unique), 이름, 부서, 비밀번호(해시)
- **Project**: 이름, 고객사, 설명, 생성자
- **Membership**: user, project, role(OWNER / MEMBER)
- **ProjectToken**: project, token, revoked
- **ProjectModule**: project, 모듈명 (VCS 8모듈 중 선택)

## 비기능

- 사내 폐쇄망, 외부 API 미사용
- 비밀번호는 해시로 저장
- 저장소: Oracle
